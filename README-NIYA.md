# راهنمای نصب — NIYA AI

## قدم ۱ — پکیج‌های لازم (اگه قبلاً نصب نکردی)
```
npm install framer-motion clsx tailwind-merge @splinetool/react-spline @splinetool/runtime
```

## قدم ۲ — کپی فایل‌ها
این زیپ را باز کن و همه‌ی پوشه‌ها (`app`, `components`, `lib`) را داخل پوشه‌ی
`niya-app` بریز — وقتی پرسید Replace/Merge بزن، قبول کن (فایل‌های قبلی جایگزین می‌شوند).

## قدم ۳ — اجرا
```
npm run dev
```
بعد برو به `localhost:3000`

## صفحات ساخته‌شده
- `/` خانه (Hero سه‌بعدی + دوره‌های ویژه)
- `/courses` لیست همه‌ی دوره‌ها
- `/courses/[slug]` صفحه‌ی اختصاصی هر دوره
- `/about` درباره ما
- `/contact` تماس با ما (فرم نمایشی)
- `/admin` پنل ادمین (نمایشی — بدون ذخیره‌سازی واقعی)

## قدم بعدی پیشنهادی
وقتی ظاهر را دیدی و پسندیدی، مرحله‌ی بعد اضافه‌کردن دیتابیس و لاگین واقعی
برای پنل ادمین است.
